# AI Resume Feedback Backend

Backend service for an AI-powered resume feedback tool built using Spring Boot.

## Tech Stack
- Java 17
- Spring Boot
- Spring Security
- JPA / Hibernate
- PostgreSQL
- AI API (Gemini / OpenAI)

## Features
- User authentication (JWT)
- Resume analysis using AI
- Feedback storage and history
